📖 Comandos básicos

Os primeiros comandos que você deve aprender.

🖨️

print()

Mostra informações na tela.

print("Olá, mundo!")
⌨️

input()

Recebe informações digitadas pelo usuário.

nome = input("Digite seu nome: ")
print(nome)
📦

Variáveis

Armazenam informações.

nome = "João"
idade = 20
altura = 1.75
🔢

int()

Converte para inteiro.

idade = int(input("Idade: "))
🔢

float()

Converte para decimal.

preco = float(input("Preço: "))
🔤

str()

Converte para texto.

numero = 10
texto = str(numero)

🔀 Condições

Faça o programa tomar decisões.

❓

if

Executa código quando uma condição é verdadeira.

idade = 18

if idade >= 18:
    print("Maior de idade")
↪️

else

Executa código quando a condição é falsa.

if idade >= 18:
    print("Adulto")
else:
    print("Menor")
🔀

elif

Testa outra condição.

if idade >= 18:
    print("Adulto")
elif idade >= 13:
    print("Adolescente")
else:
    print("Criança")

🔁 Repetições

Execute o mesmo código várias vezes.

🔄

for

Percorre uma sequência.

for numero in range(5):
    print(numero)
♻️

while

Repete enquanto uma condição for verdadeira.

contador = 0

while contador < 5:
    print(contador)
    contador += 1
🔢

range()

Cria uma sequência de números.

for i in range(1, 6):
    print(i)

📦 Listas e estruturas

Organize vários valores.

📋

list

Armazena vários valores.

frutas = ["maçã", "banana", "laranja"]
➕

append()

Adiciona um item.

frutas.append("uva")
📊

len()

Retorna a quantidade de elementos.

print(len(frutas))
🗂️

dict

Armazena chave e valor.

pessoa = {
    "nome": "Carlos",
    "idade": 25
}

🧩 Funções

Crie blocos de código reutilizáveis.

⚙️

def

Cria uma função.

def saudacao():
    print("Olá!")
📥

Parâmetros

Enviam informações para uma função.

def saudacao(nome):
    print("Olá", nome)

saudacao("Maria")
📤

return

Retorna um resultado.

def soma(a, b):
    return a + b

print(soma(5, 3))

📚 Mais códigos Python

Recursos importantes para avançar.

➕

Operadores

Faça cálculos.

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)
print(a ** b)
⚖️

Comparações

Compare valores.

idade = 18

print(idade == 18)
print(idade != 20)
print(idade > 15)
print(idade <= 30)
🧠

and / or / not

Combine condições.

idade = 20
carteira = True

if idade >= 18 and carteira:
    print("Pode dirigir")
🔤

Strings

Trabalhe com textos.

nome = "Python"

print(nome.upper())
print(nome.lower())
print(len(nome))
print(nome.replace("Python", "Java"))
📋

Tuplas

Sequências normalmente usadas sem alterações.

cores = ("azul", "verde", "vermelho")
print(cores[0])
🗃️

Sets

Conjuntos guardam valores únicos.

numeros = {1, 2, 3, 3, 4}
print(numeros)
➕

add()

Adiciona a um set.

frutas = {"maçã", "banana"}
frutas.add("uva")
print(frutas)
🗑️

remove()

Remove um elemento.

frutas = {"maçã", "banana"}
frutas.remove("banana")
🔄

enumerate()

Percorre índice e valor.

frutas = ["maçã", "banana"]

for i, fruta in enumerate(frutas):
    print(i, fruta)
🔢

sum / max / min

Operações com números.

numeros = [10, 5, 30]

print(sum(numeros))
print(max(numeros))
print(min(numeros))
⚠️

try / except

Trate erros.

try:
    numero = int(input("Número: "))
except ValueError:
    print("Número inválido!")
📁

import

Use módulos e bibliotecas.

import random

numero = random.randint(1, 10)
print(numero)

🚀 Projetos práticos

Combine vários conceitos.

🧮

Calculadora

input + float + if + operadores.

num1 = float(input("Primeiro: "))
num2 = float(input("Segundo: "))
op = input("Operação: ")

if op == "+":
    resultado = num1 + num2
elif op == "-":
    resultado = num1 - num2
elif op == "*":
    resultado = num1 * num2
elif op == "/":
    resultado = num1 / num2
else:
    resultado = "Inválida"

print(resultado)
🎓

Sistema de notas

Dicionários + listas + for.

alunos = {
    "João": [8, 7, 9],
    "Maria": [10, 9, 8]
}

for nome, notas in alunos.items():
    media = sum(notas) / len(notas)

    if media >= 7:
        print(nome, "Aprovado")
    else:
        print(nome, "Reprovado")
👥

Cadastro

while + input + lista + dict.

pessoas = []

while True:
    nome = input("Nome ou sair: ")

    if nome == "sair":
        break

    idade = int(input("Idade: "))
    pessoas.append({
        "nome": nome,
        "idade": idade
    })

for pessoa in pessoas:
    print(pessoa)
🎯

Adivinhação

random + while + if.

import random

numero = random.randint(1, 10)

while True:
    tentativa = int(input("Adivinhe: "))

    if tentativa == numero:
        print("Acertou!")
        break
    elif tentativa < numero:
        print("Maior")
    else:
        print("Menor")

⚠️ Erros comuns

Entenda mensagens frequentes do Python.

SyntaxError

Erro na estrutura/sintaxe do código.

if idade >= 18
    print("Adulto")

NameError

Nome ou variável não definida.

print(nome)

TypeError

Tipos incompatíveis em uma operação.

idade = 18
print("Idade: " + idade)

ValueError

Valor inválido para uma conversão.

idade = int("abc")

IndexError

Índice inexistente.

frutas = ["maçã"]
print(frutas[5])

KeyError

Chave inexistente em um dicionário.

pessoa = {"nome":"João"}
print(pessoa["idade"])
